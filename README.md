# Defender — AI Network Attack Forecasting MVP

Defender is an offline-first prototype for **SIH Problem Statement 26153: AI based Network Attack Forecasting from Network Traffic Data**. It turns flow and packet telemetry into a canonical network-state sequence, forecasts future infiltration risk with a temporal world-model path, maps the trajectory to analyst-friendly MITRE ATT&CK stages, and exposes perturbation-based explanations.

## Quick start

Requirements: Node.js 20+, pnpm 10+, and Python 3.10+ for the optional local model bridge. The UI and deterministic fallback do not require an API key or cloud service.

```bash
pnpm install
pnpm dev
```

Open the printed local URL, enter Defender, and use **Run Forecast → MODE A — Quick Demo → Run Defender Demo**. To use your own telemetry, choose **MODE B — Analyze Your Data**, select a CSV, PCAP, or PCAPNG file up to 50 MB, and run the forecast. The packaged fallback keeps the demo usable if the optional Python artifact is unavailable.

For a production-style build:

```bash
pnpm build
pnpm start
```

Validation commands:

```bash
pnpm check
pnpm test
```

## MVP workflow

The **How It Works** page contains the four-card live pipeline: telemetry ingestion, dual feature extraction, K-step forward simulation, and explainability. CSV uploads are header-checked in the browser; PCAP/PCAPNG files are staged for the local packet adapter. **Run Forecast** sends uploaded content through the local Express route and removes temporary files after processing.

The active forecast contract contains 22 ordered fields: flow-level ports, protocol, TCP flags, volume, duration, timing, and bidirectional ratio plus packet-level TTL, TCP-window, payload, and retransmission features. The original model artifact uses a two-layer PyTorch LSTM with a next-state head and a hazard head. The UI always labels benchmark evidence and fallback output so a result is not presented as stronger than its provenance supports.

After a forecast completes, **CYPER** receives the live result in session state. It can explain the visible risk card, timeline values and trend, predicted stage, attribution features, flagged-flow count, reliability metadata, and the model/telemetry source. CYPER's local knowledge layer also explains the repository, API path, feature contract, training objective, MITRE mapping, limitations, and judge walkthrough without a cloud dependency.

## Scope and limitations

The first public cross-day CSE-CIC-IDS2018 benchmark is retained honestly: the temporal model improves recall but does not beat the logistic-regression baseline on F1 or false-positive rate. The stage mapping is an analyst-facing abstraction, not a claim that every ATT&CK technique was identified. Packet/flow joining remains subject to the documented source-key limitation. The MVP is a decision-support demonstration, not a production intrusion-response system.
